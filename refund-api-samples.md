# Chase stub – refund API: sample requests and responses

Generated by running the v4 stub with its seed data (`chase-payments-api-v4-refund`). The responses below are the exact
bodies the code returns. Ids (`stub-txn-000001`, ...) depend on how many calls were made before; use the ids from your
own authorize responses.

## How to call it

1. Get a token (form-encoded, not JSON):

```bash
curl -X POST http://localhost:8080/stub/jpm/oauth2/token \
  -d grant_type=client_credentials -d client_id=stub-client -d client_secret=stub-secret
```

2. Authorize a payment that is captured at once (`captureMethod: NOW`) and note its `transactionId`:

```bash
curl -X POST http://localhost:8080/stub/jpm/api/v2/payments \
  -H "Authorization: Bearer <access_token>" -H "request-id: pay-1" -H "Content-Type: application/json" \
  -d '{"captureMethod":"NOW","amount":1000,"currency":"USD","isAmountFinal":true,
       "paymentMethodType":{"card":{"accountNumber":"4111111111111111","expiry":{"month":12,"year":2030}}}}'
```

3. Refund it (the request body is shown in each example below):

```bash
curl -X POST http://localhost:8080/stub/jpm/api/v2/refunds \
  -H "Authorization: Bearer <access_token>" -H "request-id: rfd-full-1" -H "Content-Type: application/json" \
  -d '{"merchant":{"merchantSoftware":{"companyName":"Payment Company","productName":"chase-payments-api","version":"0.0.1"}},
       "paymentMethodType":{"transactionReference":{"transactionReferenceId":"stub-txn-000001"}}}'
```

Amounts are in minor units (1000 = 10.00 USD). Each `request-id` must be unique per refund; repeating one returns the
first answer and never refunds twice. Cards ending 0881 / 0882 / 0883 trigger the decline / timeout / lost-response
refund scenarios (the card of the ORIGINAL payment decides for a referenced refund).

## Examples

### 1. Full refund

Payment of 10.00 USD (1000) was authorized and captured (`captureMethod: NOW`). No `amount`, so everything is refunded.

Request (`request-id: rfd-full-1`)

```json
{
  "merchant": {
    "merchantSoftware": { "companyName": "Payment Company", "productName": "chase-payments-api", "version": "0.0.1" }
  },
  "paymentMethodType": {
    "transactionReference": { "transactionReferenceId": "stub-txn-000001" }
  }
}
```

Response: HTTP 200

```json
{
  "transactionId": "stub-rfd-000001",
  "requestId": "rfd-full-1",
  "transactionState": "AUTHORIZED",
  "transactionReferenceId": "stub-txn-000001",
  "responseStatus": "SUCCESS",
  "responseCode": "APPROVED",
  "responseMessage": "Transaction approved by Issuer",
  "amount": 1000,
  "currency": "USD",
  "remainingRefundableAmount": 0,
  "approvalCode": "R100001",
  "hostReferenceId": "stub-host-stub-rfd-000001",
  "transactionDate": "2026-11-23T10:00:00Z",
  "merchant": { "merchantId": "stub-merchant", "merchantCategoryCode": "5999" },
  "paymentMethodType": {
    "card": {
      "cardType": "VISA",
      "cardTypeName": "Visa",
      "maskedAccountNumber": "XXXXXXXXXXXX1111"
    }
  },
  "paymentRequest": {
    "paymentRequestId": "stub-pr-000001",
    "paymentRequestStatus": "CLOSED",
    "refunds": [
      { "refundId": "stub-rfd-000001", "amount": 1000, "transactionStatusCode": "CLOSED" }
    ]
  }
}
```
